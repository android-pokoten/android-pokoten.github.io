# 買ったモノ
{% include thumb.html path="2026/09/ss-20260921-01.jpg" alt="motorola edge 50s pro" %}

motorola のミドルレンジ、motorola edge 50s pro を中古で購入しました。

# 検討
ポケモン GO はそこまで負荷の高いゲームではないと思っていますが、以前購入した Reno 13A の Snapdragon 6 系だと処理が重い感じがあります。そこで、もう少し処理能力が高い端末を探しました。

処理能力が高いということは端末価格も上がるので、新品はあきらめて中古などで探しました。サポート期間や性能自体の高さから、Google Pixel7a あたりを狙いましたが、Tensor コアがゲームに向かないとか、熱がこもりやすいとかの評判を見てしまい、他によい端末がないか探していました。

そんな時に、Softbank から発売された motorola edge 50s pro という機種を見つけました。Snapdragon 7 Gen3 を搭載していて、性能的には問題なさそうです。また、Softbank からいわゆる投げ売りされていた時期があり、価格も比較的抑えられています。ただ、すでに後継の edge 60 も登場しているので、安定して購入できるわけではなさそうでした。

そんななか、たまたま中古で売っているのを見つけたので、購入してみました。

# 開封
開封といっても中古品で本体のみを購入したので、シンプルに本体が届いただけでした。付属の充電器が 144W 充電対応らしいので、それが付属しないだけでも数千円程度の価値が下がっている気はしますが、今回はあきらめました。なので、開封写真は特にありません。

# 使用感
## OS
{% include thumb.html path="2026/09/ss-20260921-02.png" alt="version" %}

手元に届いた時点で Android 16 になっていました。確か、あと 1,2 年はパッチ提供はする、と言っていたと思うので、その点では安心です。Android のバージョンアップは、確か発売時から 2 世代だか 3 世代までやるといってたらしいので、そろそろ Android のバージョンアップはあまり期待できないかもしれません。

Softbank のアプリも多々インストールされていますが、無効化できないようなアプリもなかったので、それほど気になりません。

## カメラ
{% include thumb.html path="2026/09/ss-20260921-03.jpg" alt="カメラ" %}

背面カメラはメインが 5,000 万画素、そこに超広角の 1,300 万画素と 3 倍ズームの 1,000 万画素になります。

{% include thumb.html path="2026/09/ss-20260921-06.png" alt="スキャン" %}

また、カメラアプリに「スキャン」タブがあり、ドキュメントのスキャンが追加アプリなしで可能です。画面の表示を見る限り、Adobe Scan が組み込まれている様子で、書類を撮影すると自動で四隅を認識して形を整えたうえで保存してくれます。

## ディスプレイ
特徴的ともいえる、カーブエッジのディスプレイを採用しています。本体の端まで画面に覆われている印象を受けます。ただ、その影響で意図せずエッジ部分をタッチしてしまい誤動作を引き起こしたりするという評判も見かけました。自分で操作している感じでは、あまり感じないので使い方によるのかもしれないですね。

## 指紋認証
edge 50s も [Reno13 A][reno13a] と同じように画面内指紋認証です。また、センサー位置も似たような場所にあるのですが、今度は緊急通報画面へ遷移してしまい困るという印象は受けませんでした。これは、この位置でも慣れれば大丈夫、ということなんでしょうかね。

## DP1.4
edge 50s pro は Type-C ポートからの Displayport Alt Mode に対応しているので、外部ディスプレイ出力が可能です。外部ディスプレイに接続すると、マルチウインドウモードが使用できるデスクトップモードが使用できます。USB や Bluetooth のキーボード・マウスが必須ですが、しっかり文字入力したい場合などは使えるかもしれません。

{% include thumb.html path="2026/09/ss-20260921-04.jpg" alt="保護フィルム" %}

エッジの形状から保護フィルム選びが難しいと思っていましたが、こちらのフィルムはカーブにあわせた形状のガラスフィルムで、画面全体をカバーしてくれます。おそらくフィルムの端の部分のみで吸着しているので、気泡が入ったりする心配はなさそうです。ただ、このフィルムを貼ったからか、画面の明るさの自動調整が安定しないことがあるので、機会があったらはがして試してみたりする予定です。

# Pokemon GO
画面のリフレッシュレートが高いのと、Snapdragon 7 Gen3 で向上したパフォーマンスをあわせてかなりスムースに動作します。Reno13 A だと画面録画しながら GBL をするとフレームレートが低下するのが感じられましたが、edge 50s pro だと問題なく動作します。また、スペシャルわざを打つ時のスワイプ操作も、今までは画面の淵に指がかかる場合がありましたが、カーブエッジでスムースに操作できる点は予想外でした。

横幅がスリムに抑えられているのも、操作しやすくて良い点です。また、Reno13 A だと AR モードが安定しませんでしたが、edge 50s pro では AR モードも問題なく動作します。

# まとめ
中古で程度がよい端末を購入することができ、それでいて目的としたゲームのパフォーマンスが向上しているのでよかったと思います。

Type-C のディスプレイ出力ができたり、これまではできなかったこともできるようになるので、使い道を探ってみたいと思います。
