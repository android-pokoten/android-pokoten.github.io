### 事象
ThinkPad T480 のキーボードが不調になりました。まず Enter キーの反応が悪くなり、次第にほかのキーも動作不良を起こし始めて、まともにキー入力できないような状態になりました。

キートップを外して清掃してみたのですが、症状に変化はありませんでした。また、Windows だけでなく、UEFI 設定画面でも同じような状況だったので、ハードウェア的な故障と考えました。

### 対策
キーボードを購入して交換したところ、改善しました。

### 詳細
今でもキーボードは部品で購入可能です。こういうところは ThinkPad の良いところですね。また、キーボード部分は簡単に取り外せますし、元が日本語キーボードのモデルでも、英語キーボードの部品を購入して取り付けることも可能です。

交換の手順です。まず、本体裏側のラッチ 2 か所を解除してバッテリーを取り外します。モデルによっては内蔵バッテリーがあるので、その場合は UEFI 設定から内蔵バッテリーもオフにします。

{% include thumb.html path="2026/10/ss-20261004-01.jpg" alt="バッテリー" %}

そのまま裏面のネジを 2 か所 (写真の青丸で囲んだネジ) を外します。普通のプラスネジです。今回、取り外すネジはこの 2 か所のみです。

{% include thumb.html path="2026/10/ss-20261004-02.jpg" alt="ネジ" %}

表に返して液晶を開き、青矢印のようにキーボードを液晶側へ押し上げます。

{% include thumb.html path="2026/10/ss-20261004-03.jpg" alt="キーボード押し上げ" %}

すると、キーボードが全体的にずれ、このように下側の爪が外れます。

{% include thumb.html path="2026/10/ss-20261004-04.jpg" alt="爪はずれ" %}

ちなみに、右 Ctrl や矢印キーの下あたりにフラットケーブルがあるので、ここにダメージを与えないように注意します。

{% include thumb.html path="2026/10/ss-20261004-05.jpg" alt="フラットケーブル" %}

キーボードを裏返します。パームレストにキーボードを乗っけるような感じですね。そうすると、フラットケーブルをシステムボードに固定するコネクタが見えるので、これを外します。

(キーボードとバックライトで 2 本あります)

{% include thumb.html path="2026/10/ss-20261004-06.jpg" alt="キーボード外し" %}

このようにコネクタ部の黒い爪を持ち上げるとロックが解除されてケーブルが外せます。取り付ける際は、コネクタの奥までケーブルを押し込んで、爪をおろせばロックされます。

{% include thumb.html path="2026/10/ss-20261004-07.jpg" alt="ロック" %}

古いキーボードを外したら、新しいキーボードを取り付けて、逆の手順で組付ければ完了です。キーボードを交換したら動作不良は改善しました。
