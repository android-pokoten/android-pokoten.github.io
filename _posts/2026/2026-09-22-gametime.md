### 事象
{% include thumb.html path="2026/09/ss-20260922-01.png" alt="テクスチャ非表示" %}

motorola edge 50s pro でポケモン GO をやっていて、時々テクスチャ？が表示されないような症状があります。上の画面はポケモンの背景部分が抜けていますが、それだけでなく、いろいろな部分がこうなります。タスク一覧の背景がこうなってしまって、文字が読みづらいなどの実害もあります。

### 対策
「ゲームタイム」をオフにしたところ、この症状は治まりました。

### 詳細
以前、同じ motorola の moto g64 を使用していた時も、同じ症状がありました。その時は端末性能だったりでこういうこともあるかと思っていましたが、Reno13 A では発生しなかったのが edge 50s pro では発生しました。

となると、共通部分として　motorola による何かが影響している可能性が出てきます。そこで、ゲームアシスタントとして動作する「ゲームタイム」を以下の通りオフにしてみました。

まず、アプリ一覧より「ゲーム」を起動します。

{% include thumb.html path="2026/09/ss-20260922-02.png" alt="ゲーム" %}

起動したら左上のハンバーガーメニューをタップします。

{% include thumb.html path="2026/09/ss-20260922-03.png" alt="メニュー" %}

メニューから「設定」をタップします。

{% include thumb.html path="2026/09/ss-20260922-04.png" alt="設定" %}

設定画面で「ゲームタイム」をタップしてオフにします。

{% include thumb.html path="2026/09/ss-20260922-05.png" alt="設定" %}

この状態でポケモン GO を起動すると、テクスチャが表示されない症状は発生しませんでした。

# 補足
{% include thumb.html path="2026/09/ss-20260922-06.png" alt="キャッシュ消去" %}

アプリの設定から「キャッシュの削除」をすると、いったん症状が収まります。ただ、しばらくすると再発します。なので、ゲームタイムが不定期にキャッシュデータを破損してしまうのでは、と思っています。
