### 事象
普段使用している Xiaomi Watch S1 Active が、バッテリー残量は 50% 以上あるのに急に電源が切れる症状が発生するようになりました。2023 年に購入して 3 年が経過したので、バッテリーの寿命のように見えます。

### 対策
バッテリーを交換したら症状が治まりました。

### 詳細
Xiaomi Watch S1 Active のバッテリーは、「BW40」という型番で検索できるようです。

{% include thumb.html path="2026/10/ss-20261025-01.jpg" alt="BW40" %}

工具なども付属した一式で購入できます。それでは分解していきます。

{% include thumb.html path="2026/10/ss-20261025-02.jpg" alt="ネジ位置" %}

まずはストラップを外します。ストラップを外したら、ストラップのピンを固定する部分にネジで裏蓋が固定されているので、赤丸で囲んだネジを 4 か所外します。

{% include thumb.html path="2026/10/ss-20261025-03.jpg" alt="裏蓋" %}

ネジを外したら裏蓋を開けます。ただ、結構しっかり固定されているのと、裏蓋にとっかかりがないので、少し開けづらいと思います。また、写真のように本体と裏蓋がフラットケーブルで接続されているので、工具を差し込みすぎたり、外すときに勢いをつけすぎたりしないように注意が必要です。

裏蓋が外れたら、フラットケーブルを固定しているブラケットを外すため、赤丸で囲んだネジを外します。

{% include thumb.html path="2026/10/ss-20261025-04.jpg" alt="ブラケット" %}

ブラケットを外したら、裏蓋とつながっているフラットケーブルを外します。(外さなくてもバッテリー交換は可能ですが、誤ってケーブルを損傷しても困るので、外したほうが作業はやりやすいと思います)

{% include thumb.html path="2026/10/ss-20261025-05.jpg" alt="フラットケーブル" %}

これで裏蓋が外れます。そうしたら、赤丸で囲んだバッテリーのフラットケーブルを外し、両面テープで固定されているバッテリーを外します。結構強力なテープで固定されているので、注意して外します。

{% include thumb.html path="2026/10/ss-20261025-06.jpg" alt="バッテリー" %}

これでバッテリーが外れました。あとは付属の両面テープを使って新しいバッテリーを固定し、組付けていくだけです。バッテリーのケーブルが、コネクタが小さく接続するのが大変でした。

{% include thumb.html path="2026/10/ss-20261025-07.jpg" alt="完成" %}

組み立てて正常に動作することを確認します。バッテリーの消費具合は正常になりましたが、スマートフォンとの同期がうまくいかない症状が出たので、一度時計をリセットして再接続しました。一応、バッテリーを交換したときはリセットしたほうが無難かもしれないですね。
